# Licence and dependency inventory

## This project

The repository does not yet declare a licence for its own code. The
repository owner should choose one; until then, all rights are reserved by default. The
third-party components below keep their own licences regardless of that
choice.

Notes:

- The font bitmaps are a derived rendering of DejaVu glyphs. The
  Bitstream Vera licence permits redistribution in this form, provided the
  copyright and licence notice are included, and forbids selling the fonts on
  their own. Font names are only used to describe the source.
- The GitHub and Discord icons come from Simple Icons, whose files are CC0.
  CC0 does not cover the trademarks. The icons are used only as nominative
  identifiers next to the badge wearer's own username on that platform, are not
  recoloured or reshaped (only rasterised to 1 bit), and imply no
  endorsement. The brand guidelines (https://github.com/logos,
  https://discord.com/branding) could not be fetched from the build
  environment (network policy), so **the repository owner should review them** before
  any public release. Simple Icons' `DISCLAIMER.md` is kept with the files.
- `cmake/pico_sdk_import.cmake` is a copy from the Pico SDK (BSD-3-Clause)
  and keeps its original header.
- Distribute `docs/LICENSES.md` and `third_party/licenses/` together with
  any release UF2 to satisfy the notice requirements.
