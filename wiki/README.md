# Versioned wiki source

The pages in this directory are **reviewed with the firmware**, via pull requests, rather than edited directly in GitHub's separately versioned Wiki Git repository.

- Begin at [Home](Home.md); browse [_Sidebar](_Sidebar.md).
- Repo-relative links to `../docs/`, `../config/` and other wiki pages are intentional and reviewable in this repository.
- Do not publish pages by copying them into the separate GitHub Wiki without resolving those repository-relative links and verifying the target branch's version.
- Publishing instructions and link checks: [Publishing the wiki](Publishing-the-Wiki.md).

This documentation deliberately contains **no personal photos, contact information, badge serials, tokenized Studio URLs or private backups**.
